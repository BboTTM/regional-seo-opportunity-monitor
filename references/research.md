# 研究规则

## 来源与地区

先读本区 sources 和历史；公共来源种子需要每轮验证。土耳其示例包含财经媒体、当地语社媒、Trends TR、社区及官方机构入口；阿塞拜疆单独使用自己的来源。去重同一发布主体的多个平台和新闻稿传播链，不用语言代替地理受众证据。

每日检查核心网站和可用的 Trends、本地社区、公开 Telegram 等；周一补查周度来源、当地语言平台检索、官方日历和站外新来源。全球 CoinGecko、CoinMarketCap 热榜仅作发现入口。YouTube 只读标题/简介应标为元数据；页面参数 geo/countryCode 不能代替正文实际地区标签。核心平台受限时至多换一个公共方法，记录缺口，不加入私人群或绕过限制。

监管、税务和货币政策回到当地官方原文。不可把土耳其业务背景当阿塞拜疆规则；英语投放不自动等于符合当地法规。产品支持和 CTA 需验证当前品牌、地区和用户资格。

## 指标

- 媒体：窗口内去重文章、独立主体、日期；样本提及次数不是全网声量。
- 社媒：逐平台记录互动单位、帖子年龄和抓取时间，不把不同平台指标相加；缺历史快照不能回填过去互动量。
- 搜索：Trends 0–100 是相对指数，不是人数。35 日同批可比序列的最近完整七日日均相对前 28 日日均增长，基线为零或缺失时不算增长。Trending Now 的量级和涨幅保留原始窗口，不冒充月搜索量。
- 同地域、同查询类型、同归一化批次才可比较。已验证本地语言热度、地域英语需求和全球英文供给分别陈述；英语 SERP 未验证地理位置时只能作供给样本。

## 选题分层与去重

有地域搜索数据及明确窗口可称已验证搜索升温；两个独立主体仅支持跨来源讨论；单来源未获搜索支持放观察。无证据不能承诺低竞争、排名、获客或转化。

主题稳定 ID 按地区维护；不同拼写、语言和普通新报道映射同一主题。详细正文优先本期新发现；旧词有变化最多一句。事件续篇必须有原阶段、新阶段、新事实原文和前期关联，仅描述变化。预热→开幕→结束复盘可构成续篇，换标题或持续热度不构成。新词不足不拿旧词补数，无合格新词可交付空主榜。

土耳其大小写处理需保留 ç/ğ/ı/İ/ö/ş/ü；阿塞拜疆语保留本地字符。语义合并由研究者核验，脚本不靠关键词相似度自动认定同一事件。
